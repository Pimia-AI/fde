Las piezas de tu vertical.En un mismo backend.

Nuestra instalación autoalojada de InsForge reúne datos, acceso, archivos, funciones e IA. El FDE la opera desde el panel, el SDK o la CLI con sus agentes.

Construye más rápido

Como FDE, construye el MVP con el SDK y tus agentes de código.

app.js · @insforge/sdk
import { createClient } from '@insforge/sdk'
const insforge = createClient({
  baseUrl: 'https://insforge.taskai.work',
  anonKey: '<tu anon key>',
})
const { data } = await insforge.database.from('jobs').select('*')
npx -y @insforge/cli link --api-base-url https://insforge.taskai.work --api-key <tu api key>
npx -y @insforge/cli db query "select 1"
npx -y @insforge/cli functions deploy intake --file ./intake.js

Ejemplo de conexión: sustituye la anon key y adapta la tabla jobs a tu modelo de datos.

Todo lo que necesitas para producción

Las piezas que el FDE necesita para construir el MVP de su vertical.

Autenticación

Registro y acceso por email o Google. Gestiona usuarios y sesiones de tu aplicación.

Base de datos Postgres

Tablas, relaciones y reglas de acceso. Consulta tus datos mediante API REST o SDK.

Edge Functions

Ejecuta la lógica de tu vertical en el backend y conecta los servicios que necesita tu app.

Storage

Almacena imágenes y documentos en buckets con sus propias reglas de acceso.

Pasarela de modelos IA

Conecta tu aplicación a los modelos y proveedores configurados desde una interfaz común.

Realtime

Publica eventos y suscríbete a canales para llevar las actualizaciones a tu aplicación.

Tareas programadas

Programa la ejecución de trabajos recurrentes como parte de la lógica de tu backend.

Vectores

Almacena embeddings y consulta por similitud para incorporar búsqueda semántica a tu MVP.

Seguro para que los agentes operen

Como FDE, define los permisos con los que trabajarán tu app y tus agentes.

RLS en Postgres

Define políticas por fila para controlar qué datos puede leer y modificar cada usuario.

Claves separadas anon / admin

Usa la anon key en tu app y reserva las credenciales de administración para entornos de confianza.

Copias de seguridad

Coordina las copias y las pruebas de restauración con el equipo que administra nuestro servidor.
